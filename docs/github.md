# Repositorio de equipo

Proyecto: [GabrielGutierrez21/semaforo-co2-uai](https://github.com/GabrielGutierrez21/semaforo-co2-uai), rama `main`. Este repositorio privado mantiene juntos firmware, documentación, pruebas y CAD. El repositorio público `SEMAFORO_AMBIENTAL` del Grupo 9 quedó intacto.

## Cómo continuar

1. Clonar el repositorio y trabajar siempre desde una rama o una copia local actualizada.
2. Registrar en cada commit el cambio y su prueba. Ejemplos: `Cableado SCD40 verificado en protoboard`, `Carcasa ajustada a medidas reales`, `Ensayo de 5 minutos documentado`.
3. Subir fotos del montaje, lecturas reales, video de la demostración y una tabla de problemas, correcciones y resultados cuando existan. No fabricar datos ni presentar el STL conceptual como validado.
4. Invitar al equipo y al docente desde la configuración de GitHub si necesitan colaborar; revisar antes qué permisos se otorgarán.

El repositorio es privado. No subir contraseñas de redes institucionales, datos personales, códigos de verificación ni mediciones privadas. La clave de ejemplo del punto de acceso local del ESP32 está en el firmware para la demostración; cámbienla antes de usar el dispositivo fuera de un entorno de prueba o hacer público el repositorio.

La guía del curso pide código comentado, circuito actualizado y registro de iteraciones. No especifica, en el documento adjunto, una obligación explícita de GitHub; este repositorio organiza esas evidencias y facilita compartirlas.

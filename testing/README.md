# Pruebas y validación

El [protocolo](protocolo.md) detalla las comprobaciones del circuito, la red local, la web, el historial y el reinicio. Registrar valores **reales** del dispositivo en CSV, fotos de la OLED/LED y capturas de la web desde el celular. El registro no se sustituye con una simulación gráfica.

Las fotos disponibles de piezas y montaje parcial están en [hardware/fotos/](../hardware/fotos/). Agregar aquí los resultados fechados de las pruebas, sus condiciones y el análisis cuantitativo cuando el equipo los mida. La clasificación visual responde a cambios relativos de TVOC, no a límites sanitarios.

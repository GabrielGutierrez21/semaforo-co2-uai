# Pruebas y validación

El [protocolo](protocolo.md) define condiciones, pasos y criterio de éxito para las pruebas reales. A la fecha **no hay registros numéricos, fotos de la pantalla funcionando ni captura de un dashboard** que permitan certificar resultados; las imágenes de [`hardware/fotos/`](../hardware/fotos/) documentan piezas y un montaje parcial.

Al ejecutar el protocolo, agregar aquí un archivo CSV con hora, TVOC, eCO₂ estimado, estado LED, evento del botón y observaciones; acompañarlo con los registros originales del Monitor Serie y fotos fechadas. No incluir mediciones sintéticas como si fueran reales. Los resultados deben explicar la utilidad y las limitaciones de TVOC para el problema original de calidad de aire en una sala.
